# 3D Модeller - Clone SketchUp

Полнофункциональное веб-приложение для 3D моделирования, вдохновлённое SketchUp.

## 🚀 Запуск

Откройте файл `index.html` в вашем браузере.

## ✨ Возможности

### Создание объектов
- **Куб** - создание кубических форм
- **Сфера** - создание сферических объектов
- **Цилиндр** - создание цилиндрических форм
- **Плоскость** - создание плоских поверхностей
- **✏️ Карандаш** - рисование линий и создание форм по точкам (как в SketchUp!)
  - Умное отслеживание пересечений и осей
  - Привязка к точкам, линиям и осям (X, Y, Z)
  - Визуальные подсказки направлений (inference engine)
  - Отображение расстояний в реальном времени

### Инструменты трансформации
- **Перемещение (G)** - перемещение объектов в 3D пространстве
- **Вращение (R)** - поворот объектов по осям
- **Масштабирование (T)** - изменение размера объектов

### Управление объектами
- Выбор объектов кликом мыши
- Изменение цвета объектов
- Дублирование объектов (D)
- Удаление объектов (Delete)
- Панель свойств с точными координатами

### Навигация
- **Левая кнопка мыши** - вращение камеры вокруг сцены
- **Правая кнопка мыши** - панорамирование
- **Колесико мыши** - приближение/отдаление
- **Кнопка "Камера"** - сброс положения камеры

### Импорт/Экспорт файлов
- **Импорт файлов SketchUp (.skp)** - с инструкцией по конвертации
- **Поддержка форматов:**
  - COLLADA (.dae) - рекомендуется
  - Wavefront OBJ (.obj)
  - STL (.stl)
  - FBX (.fbx)
  - GLTF/GLB (.gltf, .glb)
- Экспорт сцены в JSON

### Дополнительно
- Автоматическое масштабирование импортированных моделей
- Включение/отключение сетки
- Очистка всей сцены
- Система освещения с тенями
- Оси координат для ориентации

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| G | Режим перемещения |
| R | Режим вращения |
| T | Режим масштабирования |
| D | Дублировать объект |
| V | Инструмент выбора |
| L | Инструмент карандаш |
| C | Замкнуть форму и создать грань (при рисовании) |
| ← | Заблокировать ось X (красная →) |
| → | Заблокировать ось Y (зелёная ↔) |
| ↑ / ↓ | Заблокировать ось Z (синяя ↑ ВЕРТИКАЛЬ) |
| Enter | Завершить рисование с диалогом выбора |
| Delete | Удалить выбранный объект |
| Esc | Отменить рисование / Снять выделение |
| Home | Сброс камеры |

## 📝 Использование

### Создание объектов

**Готовые примитивы:**
1. Выберите инструмент создания объекта на панели инструментов
2. Объект появится в центре сцены
3. Используйте инструменты трансформации для изменения позиции/ориентации
4. Настройте цвет через палитру цветов

**Инструмент Карандаш (как в SketchUp):**
1. Нажмите кнопку "✏️ Карандаш" или клавишу **L**
2. Кликайте по сцене для создания точек
3. Точки автоматически соединяются линиями
4. **Первая точка - зелёная и крупнее**, остальные - красные
5. Жёлтая пунктирная линия показывает предпросмотр следующей линии

**Способы создать грань:**
- **Способ 1:** Кликните на первую (зелёную) точку, когда нарисуете контур → автоматически создастся грань
- **Способ 2:** Нажмите клавишу **C** (Close) после размещения 3+ точек → создастся грань
- **Способ 3:** Нажмите **Enter** после 3+ точек → появится диалог выбора (грань или линия)

**Умные подсказки (Inference Engine - как в SketchUp!):**
- **Красная линия** - рисование вдоль оси X (→)
- **Зелёная линия** - рисование вдоль оси Y (↔)
- **Синяя линия** - рисование вдоль оси Z (↑ ВЕРТИКАЛЬ вверх!)
- **Голубой круг** - привязка к существующей точке
- **Всплывающая подсказка** - показывает направление и расстояние
- Автоматическая привязка к осям при приближении
- Привязка к первой точке для замыкания контура
- **Блокировка оси стрелками (как в SketchUp!):**
  - Стрелка ← блокирует ось X (красная →)
  - Стрелка → блокирует ось Y (зелёная ↔)
  - Стрелка ↑ или ↓ блокирует ось Z (синяя ↑ ВЕРТИКАЛЬ вверх!)
  - Повторное нажатие той же стрелки разблокирует ось
- **Привязка к вершинам объектов** - автоматически находит углы кубов, сфер и других фигур

**Другие опции:**
- Для создания линии: 2 точки + **Enter** (или выбрать "Отмена" в диалоге)
- Нажмите **Esc** для отмены текущего рисования
- Привязка к сетке 0.5 единиц для точного рисования
- Созданные грани плоские (без толщины) как в SketchUp
- Отображение расстояния в метрах в подсказках
- Автоматическое определение плоскости грани (XY, XZ или YZ)

### Импорт файлов SketchUp
1. **Прямой импорт SKP:** 
   - Нажмите кнопку "Импорт"
   - Выберите файл .skp
   - Следуйте инструкциям по конвертации в поддерживаемый формат

2. **Рекомендуемый способ:**
   - Откройте файл .skp в SketchUp
   - Экспортируйте в формат COLLADA (.dae) или GLTF
   - Импортируйте экспортированный файл через кнопку "Импорт"

3. **Поддерживаемые форматы:**
   - DAE (COLLADA) - наилучшая совместимость
   - OBJ - простые модели
   - STL - для 3D печати
   - GLTF/GLB - современный стандарт
