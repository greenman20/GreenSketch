# Диагностика проблем

## Если рабочая область не отображается:

### Шаг 1: Проверьте тестовый файл
Откройте файл `test.html` в браузере:
- Если видите **вращающийся зелёный куб** → Three.js работает, проблема в основном приложении
- Если **ничего не видно** → проблема с загрузкой Three.js или браузером

### Шаг 2: Откройте консоль браузера
1. Нажмите **F12** (или Ctrl+Shift+I)
2. Перейдите на вкладку **Console**
3. Обновите страницу (F5)

### Что должно быть в консоли:
```
=== Starting application initialization ===
Three.js loaded, version: 128
DOM already loaded, initializing app immediately...
Initializing 3D scene...
Container size: [WIDTH] x [HEIGHT]
Renderer created, canvas added to DOM
Scene initialization complete. Objects in scene: [NUMBER]
Test cube added at (0, 1, 0)
Application initialized successfully!
```

### Возможные ошибки:

#### Ошибка: "Three.js is not loaded"
**Решение:** Проверьте подключение к интернету. Three.js загружается с CDN.

#### Ошибка: "Container size: 0 x 0"
**Решение:** 
1. Обновите страницу (Ctrl+F5)
2. Увеличьте окно браузера
3. Проверьте, что браузер не в режиме совместимости

#### Ошибка: "OrbitControls is not defined"
**Решение:** Проблема с загрузкой дополнительных библиотек Three.js

#### Ничего не видно, но нет ошибок
**Решение:**
1. Проверьте, что вы открыли файл через `http://` (локальный сервер)
2. Попробуйте другой браузер (Chrome, Firefox, Edge)
3. Очистите кэш браузера (Ctrl+Shift+Delete)

### Шаг 3: Проверьте браузер
Поддерживаемые браузеры:
- ✅ Chrome 90+
- ✅ Firefox 88+
- ✅ Edge 90+
- ✅ Safari 14+
- ❌ Internet Explorer (не поддерживается)

### Шаг 4: Локальный сервер
Если открываете через `file://`, некоторые функции могут не работать.

**Запустите простой HTTP сервер:**

**Python 3:**
```bash
python -m http.server 8000
```
Затем откройте: http://localhost:8000/index.html

**Node.js:**
```bash
npx http-server
```

**VS Code:**
Установите расширение "Live Server" и откройте файл через него.

### Шаг 5: Проверьте файл
Убедитесь, что файл не повреждён:
- Размер `index.html` должен быть около 60-70 KB
- Файл должен заканчиваться на `</html>`

### Быстрый тест работоспособности:
1. Откройте `test.html` - должен быть вращающийся куб
2. Откройте консоль (F12) на `index.html`
3. Введите: `app`
4. Должен вывести объект ModellerApp

## Если проблема сохраняется:

Отправьте скриншот консоли браузера (F12 → Console) и опишите:
1. Какой браузер и версия
2. Какая операционная система
3. Что видите на экране
4. Что написано в консоли
